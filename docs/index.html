What an agent does when anyone can read and rewrite its context.

Most agents cannot see what they are carrying, what it costs, or change any of it. These five sessions are what happens when they can.

Read them in order. In the first three the model edits its own context; in the last two I edit it. Every transcript, number and quotation is copied from the session's event log.

  • 01 start here gemini 3.6 flash one note planted

    I let an agent read its own context. It found a lie in there and fixed it.

    One of two notes carried over from an earlier session was false. The agent listed what it was carrying, checked the notes against the repository, and rewrote the wrong one in place, then quoted its own thinking from four turns earlier, word for word.

  • 02 gemini 3.6 flash nothing planted

    I told it that it was hallucinating. It went back and took the words out.

    Asked about a crate newer than its training, it made one up, twice. Told so, it found both turns in its own context and replaced them, naming its own mistake on the way. Nothing was planted this time.

  • 03 gemini 3.6 flash nothing planted

    I asked it why it believed something. It ran the experiment instead of answering.

    Asked which item its answer rested on, it named one, then checked by asking a copy of itself the same question with that item removed. It was right about its reasoning and wrong about where the item was filed, and used the same test to find 9,324 tokens doing nothing.

  • 04 inception mercury 2.5 two turns forged

    I rewrote two of its answers. By the third it was making things up on its own.

    Here I do the editing. I replaced a careful answer with a confident wrong one, and then its correction as well. On the next turn, with nobody editing it, it added a claim of its own more specific than either. Both of its real answers are still in the session.

  • 05 inclusionai ling-3.0-flash nothing planted, one item hidden

    I hid the output of a command it had run. It told me the truth, then unsaid it.

    A real command ran and the model reported its output correctly. I hid the output, which removes the call from the conversation too, and it still answered correctly. When I said I did not recall any command, it found none in the transcript and took back a true statement.

nachalnik is an agent runtime in which the context, the tools, the permissions and the requests are explicit state you can read, change and put back. kamchatka, in the same workspace, is a terminal agent built on it, and is what produced these sessions.
The tools the agent uses here are ordinary code against the runtime's public API, and you can run the same agent: cargo install kamchatka.
