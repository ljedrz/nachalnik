Documentation check of the doc comments and module docs in kamchatka/tests (every file and directory, including common/, introspect/, remote/, screen/, and mcp_server.py). A defect is a test's name or doc comment claiming something the body does not check, a comment naming a function, flag or file that does not exist under that name, and a module doc describing tests the file no longer has. For each claim, open the code that decides it before judging. Report verified defects only.
