Documentation check of the messages a caller or a person reads when something is refused: the Display and doc comments of every Error variant in nachalnik/src/error.rs, nachalnik-providers (every error type), nachalnik-mcp and nachalnik-eval/src/error.rs, and the refusal strings in kamchatka/src (grep for 'refused', 'not permitted', 'cannot', 'no such', 'unknown'). A defect is a message that names a flag, key, command, limit or action that does not exist under that name or states a limit different from the constant enforcing it, and a variant whose doc says when it is returned where the code returns it in other cases or not at all. For each claim, open the code that decides it before judging. Report verified defects only.
