Documentation check of the doc comments and module docs in the test code of nachalnik/tests (every file and directory, including common/, context/, kernel/), nachalnik-providers/tests, nachalnik-mcp/tests (and foreign_server.py) and nachalnik-eval/tests. A defect is a test's name or doc comment claiming something the body does not check, a comment naming a function, invariant or file that does not exist under that name, and a module doc describing tests the file no longer has. For each claim, open the code that decides it before judging. Report verified defects only.
